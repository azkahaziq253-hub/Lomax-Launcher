# Kebijakan Privasi — Lomax Launcher

Terakhir diperbarui: 3 November 2026

Lomax Launcher ("aplikasi") adalah launcher open-source untuk Minecraft: Java Edition.

1. **Data yang dikumpulkan.** Aplikasi tidak mengumpulkan, menjual, atau mengirim data pribadi ke server milik pengembang.
2. **Login akun.** Login dilakukan langsung ke layanan Microsoft/Xbox/Minecraft. Token login disimpan hanya di perangkat Anda untuk menjalankan game.
3. **Jaringan.** Internet dipakai untuk mengunduh file game, library, Java runtime, dan mod dari server Mojang, GitHub, Modrinth, dan CurseForge. Layanan tersebut tunduk pada kebijakan privasinya masing-masing.
4. **Mikrofon.** Izin mikrofon hanya dipakai jika Anda menggunakan mod voice chat di dalam game.
5. **Log & laporan crash.** Disimpan di perangkat Anda dan hanya dibagikan bila Anda sendiri yang mengirimkannya.
6. **Hapus data.** Hapus akun di dalam aplikasi atau uninstall aplikasi untuk menghapus semua data lokal.
7. **Anak-anak.** Aplikasi tidak ditujukan untuk anak di bawah 13 tahun.
